# lhitches Claude SEO plugins marketplace

Index of Claude Code plugins for SEO by Lawrence Hitches. Each plugin lives in its own repository; this one only lists them so a single marketplace add covers every release.

```
/plugin marketplace add lhitches/claude-seo-plugins
/plugin install seo-page-design@lhitches
/plugin install internal-linking@lhitches
/plugin install query-templates@lhitches
/plugin install schema-specialist@lhitches
/plugin install seo-boardroom@lhitches
/plugin install reddit-extract@lhitches
/plugin install hawk-seo-skills@lhitches
/plugin install google-trends-mcp@lhitches
```

| Plugin | Repository | What it does |
|---|---|---|
| seo-page-design | lhitches/seo-page-design | Design and gate a page before it ships: /page-design, /line-edit, /copy-audit |
| internal-linking | lhitches/internal-linking | Plan or audit internal links: anchors, authority flow, source-page ranking |
| query-templates | lhitches/query-templates | Own query patterns, not only topics, from your Search Console export |
| schema-specialist | lhitches/schema-specialist | JSON-LD entity graph, type atlas, validation, site sweep |
| seo-boardroom | lhitches/seo-boardroom | Five adversarial advisors plus a Chair: SHIP, FIX FIRST or KILL |
| reddit-extract | lhitches/reddit-extract | Buyer-voice research from Reddit threads, no API key |
| hawk-seo-skills | lhitches/hawk-seo-skills | Eight Hawk Academy SEO skills, no API keys |
| google-trends-mcp | lhitches/google-trends-mcp | Google Trends as four Claude tools, no API key |

The full list, with what each does and its install line, is at https://www.lawrencehitches.com/claude-seo-plugins/
